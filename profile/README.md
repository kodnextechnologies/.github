# KodNex Technologies

We build **[NexWall](https://nexwall.kodnextech.com/wallpaper-api)**, a free wallpaper REST API made specifically for wallpaper apps: curated 4K portrait wallpapers in 50+ categories and looping live MP4 wallpapers, as simple JSON. The free plan includes 100 requests/day with no credit card.

**Start here:** [free-wallpaper-api](https://github.com/kodnextechnologies/free-wallpaper-api): endpoints and copy-paste examples in 7 languages.
